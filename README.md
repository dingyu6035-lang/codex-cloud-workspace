# Codex Cloud Workspace

A general-purpose repository for projects and files that Codex should be able to access in cloud tasks.

## Getting started

1. Add each project in its own directory.
2. Include the project's source, documentation, and reproducible setup instructions.
3. Keep credentials, API keys, personal data, large generated artifacts, and local-only files out of this public repository.
4. Add project-specific deployment configuration only after choosing a framework and hosting platform.

## Codex

Open this repository as the project for Codex cloud tasks. Cloud execution still depends on the task environment having the required runtimes, dependencies, and approved secrets/network access.
