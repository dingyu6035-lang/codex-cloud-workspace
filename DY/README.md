# DY 工作区

`DY/` 是用户 DY 在此仓库中的固定工作目录。后续新增项目、提交内容、说明和交接资料默认放在这里。

## 目录与人员约定

- 每个独立项目放在 `DY/<项目名>/`，保留项目自己的运行说明和依赖文件。
- 各协作者在各自约定的目录内工作；未经明确任务安排，不修改其他人的内容。
- 公共配置或跨目录修改需说明影响范围，并在交接中记录。
- 不存放密钥、凭据、私人数据或大型生成文件。

## 版本约定

- 实现任务使用独立分支 `dy/<任务名>`，例如 `dy/wanhu-flight-controls`。
- 开始前检查当前分支及工作区，保留已有修改；每次提交只处理一个明确任务。
- 通过 Pull Request 说明变更和验证结果，经过协作方审阅后合并到 `main`。
- 不强制推送，不覆盖他人分支；发生冲突时保留双方意图，记录处理结果。
- 目录用于约定归属，分支用于隔离开发版本；它们不构成访问权限隔离。需要限制读写权限时，应另行配置仓库权限或使用独立仓库。

## 工作交接

开始和结束任务时查看并更新 [HANDOFF.md](HANDOFF.md)。项目变多后，可在各项目目录维护独立交接文件，并在总表链接。

交接至少写明负责人、项目路径、任务目标、分支及已有提交、完成内容、验证结果、待办和下一步。尚未运行的检查必须注明“未运行”；只有已提交的改动才填写对应提交号。
